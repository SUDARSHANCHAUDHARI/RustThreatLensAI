# Project Plan

## Current MVP

- Parse Linux auth logs, nginx access logs, and Docker/app logs.
- Detect SSH brute force, suspicious web requests, credential exposure, and multi-signal IPs.
- Generate machine-readable events, findings, and IP risk tables.
- Generate Markdown incident and triage reports.
- Keep summary generation provider-neutral and offline by default.

## Portfolio Polish Goals

- Make the CLI demo clear and repeatable.
- Provide reports that look useful to a SOC analyst.
- Keep all sample data safe and synthetic.
- Document the future API/UI architecture without overbuilding it early.
