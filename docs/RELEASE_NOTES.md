# Release Notes

## v0.1.0-mvp

Initial portfolio MVP for ThreatLens AI.

## Added

- Auth, nginx, and Docker log parsing
- SSH brute-force detection
- Suspicious HTTP path and user-agent detection
- Credential-like material detection
- Multi-signal IP correlation
- Deterministic summary provider boundary
- Incident report with priority queue and recommended next steps
- IP risk table JSON
- Compact triage report
- Unit tests and GitHub Actions CI
- Docker CLI demo path

## Safety

- Offline deterministic summary by default
- Synthetic sample logs
- No external AI calls in the MVP
