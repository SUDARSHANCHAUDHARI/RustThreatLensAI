# Roadmap

This is a solo-maintained roadmap. Items are practical possibilities, not promises.

## Planned

- Add configurable brute-force thresholds.
- Add Markdown incident summary output.
- Add more parser fixtures for common auth and web logs.

## Maybe Later

- Add allowlist support for known internal IP ranges.
- Add finding severity overrides.
- Add SARIF output for tooling integration.

## Not Planned

- Uploading logs to a hosted service.
- Replacing a SIEM.
- GitHub Actions workflow files.

## Feature Blog Angles

- "A local-first way to scan logs for obvious security risks"
- "Brute-force detection rules that are simple enough to trust"
- "Why secret-like strings in logs deserve their own finding type"
